# Feedback Management MVC - Enhanced

ASP.NET Core MVC practical for Visual Studio 2022.

Features:
- MVC Controller, Model and Views
- Shared Layout
- Partial View
- HTML Helpers
- Data Annotation validation
- Name, Email, Category, Rating
- Feedback, Suggestions
- Recommend Yes/No
- Submission date
- Submitted Feedback list

The project intentionally uses simple in-memory storage for the practical.
